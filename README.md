# NUKE NFL DFS HUB

DraftKings NFL DFS lineup-building hub built with Streamlit.

## Features

- DraftKings salary CSV upload
- Custom player pool
- Game-by-game slate analysis
- Betting totals, spreads, implied team totals, and slate ranks
- Multi-lineup hand building
- Team-color visualization
- FLEX late-swap optimization
- Saved lineups
- Exposure and combo analysis
- DraftKings CSV export
- Workspace save/load

## Run locally

```powershell
py -m pip install -r requirements.txt
py -m streamlit run app.py
```
